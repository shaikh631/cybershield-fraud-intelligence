# CyberShield Deployment

The root repository contains two deployable directories:

- `Fraud-Dedection/`: Vite frontend for Vercel
- `backend/`: Express API for Render

## Render backend

1. Push the root repository to GitHub.
2. In Render, choose **New > Blueprint** and select the repository.
3. Render will use `render.yaml` and deploy the `backend/` service.
4. Set these secret/environment values in the Render service:

```env
FRONTEND_URL=https://YOUR-VERCEL-DOMAIN.vercel.app
GROQ_API_KEY=your_new_rotated_groq_key
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/cybershield
```

`JWT_SECRET` is generated by Render. `GROQ_MODEL` defaults to `openai/gpt-oss-120b` and can be changed if the model is unavailable for the account.

Create a MongoDB Atlas database and allow Render's outbound access in the Atlas network settings. Store the connection string only in Render's environment variables. Users, alerts, cases, and status updates are persisted in MongoDB; the existing demo data is seeded when the collections are empty.

The API URL will be similar to:

```text
https://cybershield-api.onrender.com
```

Verify it at `/api/health`.

## Vercel frontend

1. In Vercel, import the same repository.
2. Set **Root Directory** to `Fraud-Dedection`.
3. Set the framework preset to **Vite**.
4. Add this environment variable for Production, Preview, and Development:

```env
VITE_API_URL=https://YOUR-RENDER-SERVICE.onrender.com
```

5. Deploy.

After Vercel provides its domain, update Render's `FRONTEND_URL` to that exact origin and redeploy the backend. Do not include a trailing slash.

## Local production-style check

```bash
cd backend
npm install
npm start

cd ../Fraud-Dedection
npm install
npm run build
```

Never place `GROQ_API_KEY` in Vercel variables or frontend source. It belongs only in Render's backend environment.
